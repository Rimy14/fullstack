# TODO App - Backend (Express.js)

The backend API server for the TODO application, built with Express.js and MongoDB.

## Tech Stack

- **Runtime**: Node.js 18+
- **Framework**: Express.js 4
- **Database**: MongoDB with Mongoose 8
- **Dev Tools**: Nodemon (hot reload)

## Setup

### Prerequisites

- Node.js 18 or higher
- MongoDB 6+ running locally **or** a MongoDB Atlas connection string

### Installation

```bash
cd server
npm install
```

### Environment Configuration

Create a `.env` file in the `server/` directory (one is included with defaults):

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/todo-app
```

**Using MongoDB Atlas?** Replace `MONGODB_URI` with your Atlas connection string:
```env
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/todo-app?retryWrites=true&w=majority
```

### Running the Server

```bash
# Development (with hot reload)
npm run dev

# Production
npm start
```

The server will start on `http://localhost:5000`.

## API Endpoints

### GET /api/todos
Get all TODO items, sorted by creation date (newest first).

**Response:**
```json
{
  "success": true,
  "count": 2,
  "data": [
    {
      "_id": "...",
      "title": "Buy groceries",
      "description": "Milk, eggs, bread",
      "done": false,
      "createdAt": "2025-01-01T00:00:00.000Z",
      "updatedAt": "2025-01-01T00:00:00.000Z"
    }
  ]
}
```

### POST /api/todos
Create a new TODO item.

**Request Body:**
```json
{
  "title": "Buy groceries",
  "description": "Milk, eggs, bread"
}
```

**Validation:**
- `title` is required, max 200 characters
- `description` is optional, max 1000 characters

### PUT /api/todos/:id
Update a TODO's title and/or description.

**Request Body:**
```json
{
  "title": "Updated title",
  "description": "Updated description"
}
```

### PATCH /api/todos/:id/done
Toggle a TODO's done status (true ↔ false).

### DELETE /api/todos/:id
Delete a TODO item.

## Database Model

```javascript
{
  _id: ObjectId,          // Auto-generated by MongoDB
  title: String,          // Required, max 200 chars
  description: String,    // Optional, max 1000 chars
  done: Boolean,          // Default: false
  createdAt: Date,        // Auto-generated (Mongoose timestamps)
  updatedAt: Date         // Auto-updated (Mongoose timestamps)
}
```

## Error Handling

All endpoints return consistent error responses:
```json
{
  "success": false,
  "message": "Human-readable error message"
}
```

## Assumptions & Limitations

- MongoDB must be running and accessible before starting the server
- No authentication/authorization is implemented (all todos are public)
- No pagination is implemented (suitable for small-to-medium datasets)
- CORS is enabled for all origins (development configuration)
